# PHP Блог

Простое блог-приложение на чистом PHP без фреймворков, с использованием Smarty и MySQL.

## Стек технологий

- **PHP** 8.3 + PHP-FPM
- **Smarty** 4 (шаблонизатор)
- **MySQL** 8.0
- **Nginx**
- **Docker** (контейнеры App, Web, DB)
- **SCSS** с компиляцией через esbuild
- **TypeScript** (E2E-тесты и конфигурация Playwright)

## Требования

- Docker + Docker Compose
- Node.js 18+ и npm (для фронтенд-ассетов и E2E-тестов)

## Запуск

```bash
# 1. Скопировать файл окружения и при необходимости скорректировать значения
cp .env.example .env

# 2. Собрать образы и запустить контейнеры
#    make build = docker compose up --build, контейнеры остаются запущенными
make build

# 3. Установить PHP и JS зависимости
make install

# 4. Выполнить миграции базы данных
make migrate

# 5. Наполнить базу тестовыми данными
make seed
```

Приложение будет доступно по адресу **http://localhost:8080**.

## Тесты

**Юнит-тесты** (PHPUnit):

```bash
make test
```

**Линтеры и статический анализ** (PHPCS, PHPStan, ESLint, Stylelint, tsc):

```bash
make lint
```

**E2E-тесты** (Playwright) — требуют запущенных контейнеров и E2E-данных в базе:

```bash
make seed-e2e
make e2e
```

**Все PHP-проверки разом** (PHPCS + PHPStan + PHPUnit):

```bash
docker compose exec app composer check
```

## API-документация

Swagger UI доступен по адресу **http://localhost:8080/api/docs**.

Спецификация OpenAPI: `http://localhost:8080/api/docs/openapi.yaml`.

## Структура проекта

```
config/          — Конфигурация приложения и базы данных
database/
  migrations/    — Миграции базы данных (запуск: make migrate)
  seeders/       — Классы сидеров
  seed.php       — Точка входа сидера случайных данных
  seed-e2e.php   — Точка входа детерминированного сидера для E2E
docs/            — OpenAPI-спецификация
public/          — Корень веб-сервера (index.php, скомпилированные ассеты)
src/
  Controllers/   — HTTP-слой
  Core/          — Инфраструктура (Database, View, Paginator и др.)
  Repositories/  — SQL-запросы
  Services/      — Бизнес-логика (BlogService)
  Support/       — Вспомогательные классы (Sort)
  assets/scss/   — Исходники SCSS
templates/       — Smarty-шаблоны
tests/
  Unit/          — Юнит-тесты PHPUnit
  e2e/           — E2E-тесты Playwright
```

## Контроль качества

- **PHP_CodeSniffer** — стандарт PSR-12 + строгие правила (`phpcs.xml`)
- **PHPStan** — уровень 6 (`phpstan.neon`)
- **ESLint + Stylelint** — максимально строгий режим
- **CaptainHook** — pre-commit запускает PHP-проверки; pre-push запускает линтеры и E2E-тесты

## Использование ИИ

При разработке проекта активно использовался **Claude (Anthropic)** в роли ассистента.

**Что делал ИИ:**
- Генерация кода по описанным требованиям и архитектурным решениям: репозитории, сервисы, контроллеры, миграции, сидеры, шаблоны Smarty
- Написание юнит-тестов и E2E-сценариев по готовой логике
- SCSS-стили по макету
- Конфигурация инструментов: Docker, Nginx, PHPCS, PHPStan, CaptainHook, ESLint, Stylelint, Playwright
- Рефакторинг по выявленным замечаниям: устранение дублирования, усиление типизации, удаление мёртвого кода

**Что делал я:**
- Проектирование архитектуры и принятие ключевых решений (слоистая структура, slug-маршруты, many-to-many для категорий)
- Постановка задач, итеративный code review каждого сгенерированного фрагмента
- Выявление проблем, которые ИИ не заметил самостоятельно: некорректные env-переменные в `phpunit.xml`, отсутствующий CSS-класс `.button`, мёртвые Model-классы, SQL-инъекция в репозитории
- Финальная оценка соответствия результата требованиям ТЗ
